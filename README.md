# 📚 AI की मदद से अपना पहला डिजिटल बिज़नेस - Store & Razorpay Checkout

यह एक प्रोडक्शन-रेडी डिजिटल प्रोडक्ट ई-कॉमर्स सिस्टम है जिसे विशेष रूप से **AWS EC2 सर्वर** और **Razorpay API** एकीकरण के लिए तैयार किया गया है।

## 🌟 मुख्य विशेषताएं (Features)

1. **हाई-कन्वर्टिंग लैंडिंग पेज (`/`):**
   - आधुनिक डार्क-ग्लास डिज़ाइन सिस्टम (Electric Indigo, Violet और Gold थीम)।
   - 3D ग्लोइंग ई-बुक कवर डिस्प्ले (`public/assets/ebook-cover.jpg`)।
   - 15 मिनट का रोलिंग अर्जेंसी काउंटडाउन टाइमर।
   - किताब के आधार पर 5-चरणीय फॉर्मूला (आइडिया चुनें, AI से बनाएं, डिज़ाइन करें, मार्केट करें, कमाई शुरू करें)।
   - 6 मॉड्यूल्स का विस्तृत पाठ्यक्रम और 4 मुफ़्त बोनसेस (मूल्य ₹2,999 मुफ़्त)।
   - लाइव खरीदार सूचनाएं (Social Proof Toast)।
   - अक्सर पूछे जाने वाले सवाल (FAQ Accordion) और 100% सुरक्षा गारंटी।
   - मोबाइल स्क्रीन के लिए स्टिकी बॉटम बाय बार।

2. **समर्पित चेकआउट पेज (`/checkout`):**
   - बिना किसी भटकाव का 2-कॉलम चेकआउट लेआउट।
   - ग्राहक फॉर्म (नाम, ईमेल, 10-अंक व्हाट्सएप नंबर)।
   - डायनामिक ऑर्डर बम्प (₹99 में 500+ AI प्रॉम्प्ट वॉल्ट ऐड-ऑन)।
   - ऑटो-कैलकुलेटेड मूल्य (₹199 या ₹298)।
   - आधिकारिक Razorpay SDK एकीकरण (`checkout.js`)।
   - सुरक्षित टेस्ट/डेमो मोड समर्थन (बिना लाइव कीज़ के तुरंत परीक्षण की सुविधा)।

3. **सफल भुगतान और डाउनलोड पेज (`/success`):**
   - ऑर्डर आईडी और Razorpay पेमेंट आईडी के साथ पुष्टिकरण।
   - 1-क्लिक सुरक्षित पीडीएफ डाउनलोड बटन (`/api/download/:orderId`)।
   - मुफ़्त बोनस डाउनलोड बटन।
   - VIP व्हाट्सएप सहायता और कम्युनिटी लिंक।

4. **बैकएंड और AWS EC2 रेडीनेस:**
   - Node.js + Express.js आर्किटेक्चर।
   - Razorpay Order Creation (`/api/create-order`) और Signature Verification (`/api/verify-payment`)।
   - डाउनलोड सुरक्षा (केवल भुगतान किए गए वैध ऑर्डर्स को ही फाइल डाउनलोड की अनुमति)।
   - PM2 क्लस्टरिंग कॉन्फ़िगरेशन (`ecosystem.config.js`)।
   - Nginx रिवर्स प्रॉक्सी कॉन्फ़िगरेशन (`nginx.conf`)।
   - विस्तृत डिप्लॉयमेंट गाइड (`EC2_DEPLOYMENT_GUIDE.md`)।

## 🚀 स्थानीय कंप्यूटर पर कैसे चलाएं (Local Setup)

1. रिपॉजिटरी में जाएं:
   ```bash
   cd c:\Users\lamga\Desktop\mydigitalstore
   ```
2. डिपेंडेंसीज इनस्टॉल करें (पहले से इनस्टॉल हैं):
   ```bash
   npm install
   ```
3. सर्वर स्टार्ट करें:
   ```bash
   npm start
   # या डेवलपमेंट मोड (auto-reload):
   npm run dev
   ```
4. ब्राउज़र में खोलें:
   - **लैंडिंग पेज:** [http://localhost:3000](http://localhost:3000)
   - **चेकआउट पेज:** [http://localhost:3000/checkout](http://localhost:3000/checkout)
   - **सफल पेज (प्रीव्यू):** [http://localhost:3000/success](http://localhost:3000/success)

## 💳 Razorpay API Keys कैसे जोड़ें?

`.env` फाइल खोलें और Razorpay Dashboard से अपनी चाबियां दर्ज करें:
```env
RAZORPAY_KEY_ID=rzp_live_xxxxxxxxxxxx
RAZORPAY_KEY_SECRET=xxxxxxxxxxxxxxxxxxxx
```
*(जब तक आप अपनी वास्तविक कीज नहीं जोड़ते, तब तक सिस्टम स्वचालित रूप से **डेमो/सिमुलेशन मोड** में चलता है जिससे आप पूरे फ्लो का परीक्षण बिना किसी एरर के कर सकते हैं)*
